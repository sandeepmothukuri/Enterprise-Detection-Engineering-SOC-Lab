## 1. Index Structure & Data Contracts

The platform ingests events across multiple specialized OpenSearch indices to maximize query performance and isolate retention policies:

```
soc-logs-YYYY.MM.DD    -> Raw normalized telemetry (Sysmon, Zeek, Suricata, Auditd)
soc-alerts-YYYY.MM     -> Triaged detection alerts generated by ElastAlert2 & Sigma
soc-ai-YYYY.MM         -> Autonomous CrewAI agent triage verdicts and reasoning
soc-health-YYYY.MM     -> Operational health metrics, container status, and Vector EPS
```

## 3. Data Flow & Transformations

1. **Ingest**: Logs arrive at Vector via UDP syslog (514), TCP JSON (9000), or Beats protocol (9001).
2. **Transform (VRL)**: Vector Remap Language (VRL) applies parsing rules:
   - Formats timestamp to RFC 3339.
   - Maps Windows Event ID 10 with `TargetImage: *lsass.exe` to `mitre_technique: T1003.001` and `mitre_tactic: credential-access`.
   - Normalizes network addresses into `src_ip` and `dst_ip`.
3. **Index**: Events are streamed directly into OpenSearch index `soc-logs-%Y.%m.%d`.
